# VeriEDA V0 implementation plan

> Implementation: execute inline using executing-plans and TDD. User has delegated route/implementation decisions. Keep the existing checkout.

**Goal:** A runnable evidence → state → legal proposal → independent evaluation CLI.
**Architecture:** case loader owns provenance; deterministic policy owns proposals; evaluator owns acceptance. Python 3.10+ standard library only.
**Spec:** ../specs/2026-10-21-verieda-v0.md

## Global constraints
No cloud/push, design/tool/constraint changes, or historical evidence overwrite. Preserve reset-scoped proof and UNKNOWN coverage. No fabricated cost or benefit. Candidate success is never inferred from a policy score.

## Review focus
- An unrelated native archive must not supply proof/metrics to a Smoke design.
- A self-declared reviewed proof must not silently certify a new run.
- Sparse/malformed paths or nonfinite metrics must not drive unsupported actions.
- History from a different state/candidate must not count as a real outcome.
- Candidate acceptance must require actual independent evidence, not simulated policy success.

## Tasks
1. Case loader/profile (`verieda/case.py`, `cases/gcd.json`, `tests/test_case.py`). Write tests for real pinned join and tampered identities/review. Observe RED, implement load_case(profile, smoke, acceptance), run tests. State includes provenance, metrics, gates, path diagnosis and formal contract.
2. Candidate policy (`verieda/policy.py`, `tests/test_policy.py`). Test content binding, action legality, evidence-conditioned ranking, caps and history stops. Observe RED, implement propose(state, budget_seconds, history) and validate_candidate(candidate, state). Values are bounded research proposals, not executable shell. Run tests.
3. Independent adoption and CLI (`verieda/adoption.py`, `verieda/__main__.py`, `tests/test_adoption.py`, CLI tests). RED tests for false PASS, unknown gates, contract/input/constraint mismatch and no-improvement; implement evaluate(before, after, candidate). Expose plan/evaluate and exercise real archives end-to-end; no EDA execution.
4. Full regression, package manifest update for changed CLI/module identity, documentation and diff review. Keep audit output ignored under evidence/. Commit only explicit public source/tests/docs/profile. No push.
